# Точная локация в постах группы

Раньше под каждым постом стоял пин **центра района** («примерно, на месте уточним»), потому что координат объявления в базе нет.
Теперь скрейпер OLX пытается взять точку со страницы объявления (`scraper/src/geoCoords.js`):

- точка найдена → под постом пин с подписью «точка из объявления» (если OLX отдал `show_detailed: true`)
  или «примерно, радиус ~N м» (если OLX показывает только круг);
- не найдена или на странице несколько разных точек → всё как раньше, пин района.

Координаты хранятся только в памяти на время отправки поста, в базу не пишутся (миграция не нужна, существующие записи не затрагиваются).

## ⚠️ Обязательная проверка перед полагаться на это
Формат данных на реальной странице olx.uz я проверить не мог. Запустите на 2–3 живых объявлениях:

    cd scraper
    node src/check-coords.js "https://www.olx.uz/d/obyavlenie/....html"

Скрипт покажет найденную точку (с проверочной ссылкой на карте) либо фрагменты страницы со словами lat/lon/map/address.
Если «❌ не найдены», пришлите вывод — подстрою `geoCoords.js`. Свободные шаблоны (lat/lon, ссылки на карты) включаются
переменной `GEO_LOOSE=1` и только когда на странице ровно одна уникальная точка.

## Ограничения
- Работает только для OLX (Uybor, Realting и др. не подключены: у них другая разметка).
- Точность определяет продавец: если он не включил показ точного адреса, OLX даёт круг, и пин будет ориентировочным.
- Старые посты не меняются, только новые.
