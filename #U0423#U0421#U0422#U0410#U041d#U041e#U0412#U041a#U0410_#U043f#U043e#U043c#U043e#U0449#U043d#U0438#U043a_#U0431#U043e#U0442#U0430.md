# Помощник по чату + новые команды — установка (5 шагов)

1. **Скопируйте файлы** из этой папки в проект с теми же путями
   (`client/api/_chatHelper.js` — новый, `client/api/telegram-webhook.js` и `client/api/_priceParser.js` — заменить;
   изменения в нём видны в `telegram-webhook.diff`).
2. **Supabase → SQL Editor**: выполните `supabase/16_bot_helper.sql` (таблица `bot_help_log`).
   Без неё бот просто молчит как помощник (кулдауны недоступны) — остальное работает.
3. **Vercel → Environment Variables** (желательно): `TELEGRAM_BOT_USERNAME` = юзернейм бота без `@`.
   Нужен, чтобы бот точно понимал, что ему ответили/упомянули, и не трогал команды чужих ботов.
4. **Задеплойте** клиент (Vercel).
5. **Один раз** запустите `cd scraper && node src/scripts/set-bot-commands.js` —
   в Telegram появится меню команд по «/» и кнопка «Меню».

Проверка: напишите `/`, должен появиться список команд с описаниями; `/serch` (бот предложит `/search`); `/find` → дойти до шага цены — там кнопки с вариантами и «✍️ Свой диапазон»;
ответьте на карточку фразой «звонил, не отвечает» — бот предложит сохранить заметку.
